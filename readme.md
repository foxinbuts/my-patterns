# Проект: Реализация паттернов проектирования (Patterns2026)

## Описание
Данный репозиторий создан для выполнения технического задания. В проекте будут реализованы различные паттерны проектирования на основе выделенных доменных сущностей.

## Структура проекта
- `Docs/` — документация проекта (включая Technicaltask.md)
- `src/` — исходный код (абстрактные классы и реализации)

## Доменные сущности
Подробное описание сущностей и их связей находится в файле `Docs/Technicaltask.md`.
