# Проект: Реализация паттернов проектирования (Patterns2026)

## Описание
Данный репозиторий создан для выполнения технического задания. В проекте будут реализованы различные паттерны проектирования на основе выделенных доменных сущностей.

## Структура проекта
- `Docs/` — документация проекта (включая Technicaltask.md)
- `src/` — исходный код (абстрактные классы и реализации)
  - `src/abstract.py` — абстрактный базовый класс
  - `src/models/` — модели данных
  - `src/exceptions.py` — внутренние классы исключений
- `Tst/` — автотесты

## Доменные сущности
Подробное описание сущностей и их связей находится в файле `Docs/Technicaltask.md`.

### Реализованные модели
- `range_model` — единица измерения (базовая единица + коэффициент пересчёта)
- `group_model` — группа номенклатуры
- `nomenclature_model` — номенклатура (наименование ≤ 50, полное наименование ≤ 255, группа, единица измерения)
- `organization_model` — организация (ИНН, БИК, счёт, форма собственности)
- `warehouse_model` — склад
